# North Air — HVAC alternate website

An independent five-page static demo. Build with `python3 build.py && python3 check.py`. Use `SITE_URL=https://fireworks-websitebuilder.com/demos/hvac-alt python3 build.py --prefix /demos/hvac-alt --output <storefront>/public/demos/hvac-alt` for the FireWorks storefront. Forms and scheduling/photograph tools are local examples and send nothing. Replace the fictional identity and secure delivery before client launch.
