# Muse Hair — Salon / Spa alternate website

An independent five-page static demo. Build with `python3 build.py && python3 check.py`. Use `SITE_URL=https://fireworks-websitebuilder.com/demos/salon-alt python3 build.py --prefix /demos/salon-alt --output <storefront>/public/demos/salon-alt` for the FireWorks storefront. Forms and scheduling/photograph tools are local examples and send nothing. Replace the fictional identity and secure delivery before client launch.
