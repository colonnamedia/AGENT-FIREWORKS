# Cedar & Grain — Fence & Deck Contractor

Fictional FireWorks sales-demo template. Five complete static HTML pages and five distinct original homepage photographs. Industry-specific local tools and inquiry preview; no accounts, tracking, backend, external fonts, email delivery or real scheduling.

Build with `python3 build.py && python3 check.py` or `npm run build`. No install step. Output: dist. SITE_URL is a non-secret origin/base URL override. To host in a subdirectory use `SITE_URL=https://host.example/demos/fence-deck python3 build.py --prefix /demos/fence-deck --output /absolute/output`. Verify prefixed output with `python3 check.py --dist /absolute/output --prefix /demos/fence-deck`.

Content: site.json. Layout: build.py. Styling: styles.css. Interactions: script.js. Photo prompts and attribution: PHOTO-SOURCES.md and IMAGE-PROMPTS.json. Preserve noindex on this demo; client domain, identity, approved claims and actual delivery must be configured and tested for a real launch.
